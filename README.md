# Strings Arranger 0.1

Плагин для Logic Pro (AU), других DAW (VST3) и отдельное приложение. На входе MIDI с аккордами или одной мелодией, на выходе партии струнной секции отдельными дорожками: первые и вторые скрипки, альты, виолончели, контрабасы. Стиль задаётся именем композитора. Собран на движке Choir Arranger (`ETeilor/choir-arranger`).

Суть в одном предложении: аккорды превращаются в струнную партитуру в манере выбранного композитора, предсказуемо и по правилам.

## Что есть в 0.1

- Тринадцать стилей: Вивальди, Бах, Гайдн, Моцарт, Бетховен, Чайковский, Римский-Корсаков, Дворжак, Стравинский, Барбер, Херрманн, Циммер, Свиридов.
- Сложность 0–10 общая и по партиям. От уровня партии зависит её фактура: выдержанные ноты, деташе, репетиции, альбертиевы фигуры, ломаные аккорды, аккорды на слабую долю, пиццикато, тремоло, остинато, октавные удвоения. На нуле все партии держат аккорды по учебнику.
- Состав секции: по стилю, квартет, барочный, классический, романтический, симфонический. В квартете нет контрабасов и divisi.
- Библиотека: без оптимизации, Spitfire (UACC, штрихи через CC32), дорожка на штрих (для любой библиотеки). Для библиотек пишутся перекрытие нот в легато и кривая CC1 по фразам.
- Советы в отчёте, в MIDI (текстовые события) и в нотах: какой патч взять, какой штрих у партии.
- От хорового плагина: гармонизация мелодии, «Другой вариант», слоты, закрепление партий, захват с дорожки, вставка, ноты MusicXML (альтовый ключ, контрабас записан октавой выше звучания).
- Strings Arranger Live (AU MIDI FX и VST3): аккорд раскладывается на партии в реальном времени, контрабасы октавой ниже виолончелей.

## Как пользоваться в Logic

1. Дорожка программного инструмента, на неё AU Instruments → Teilormusic → Strings Arranger.
2. Перетащите `.mid` из Finder в окно, вставьте скопированный регион (Cmd+V) или нажмите «Захват» и запустите воспроизведение.
3. Выберите стиль, состав, сложность. Партии пересчитываются сразу.
4. Выберите библиотеку и перетащите плашки партий (или «Все партии») на дорожки.

Живой режим: слот MIDI FX → Audio Units → Teilormusic → Strings Arranger Live перед струнной библиотекой.

Если Logic не видит плагин: Logic Pro → Settings → Plug-in Manager → Reset & Rescan Selection.

## Устройство

- `core/Strings.cpp`, `core/Strings.h`: струнный слой. Профили композиторов, фактуры, штрихи, советы, запись MIDI под библиотеку.
- Остальной `core/`: четырёхголосный поиск голосоведения из хорового движка (пространство имён `choir`). Струнный слой даёт ему диапазоны инструментов через `choir::Skeleton`.
- `cli/strings_main.cpp`: консольная версия, через неё идут проверки. `cli/skeleton_main.cpp`: один каркас с ключами хорового движка.
- `plugin/`: оболочка JUCE 8.0.4, два плагина с общим ядром.

## Проверки

```
cmake -S . -B build-core -DSTRINGS_BUILD_PLUGIN=OFF -DCMAKE_BUILD_TYPE=Release && cmake --build build-core -j
python3 tests/compare_golden.py tests/reference.json build-core/skeleton_cli tests   # каркас: 580 из 580
python3 tests/sweep_strings.py build-core/strings_cli tests                          # все стили, файлы и уровни
python3 tests/show.py build-core/strings_cli tests/input/02_I-IV-V-I_C.mid --style=mozart --complexity=6
```

Тест плагина без хоста и снимки интерфейса (Linux, нужен xvfb):

```
cmake -S . -B build-ui -DSTRINGS_BUILD_TESTS=ON -DCMAKE_BUILD_TYPE=Release && cmake --build build-ui --target StringsPluginTests -j3
xvfb-run -a build-ui/StringsPluginTests_artefacts/Release/StringsPluginTests tests/input/test_01_user.mid docs
```

Сборка под macOS идёт в GitHub Actions (`.github/workflows/build-macos.yml`): универсальный бинарник, `auval -v aumu Strg Tlrm` и `auval -v aumi StLv Tlrm`, установщик `.pkg` и `.dmg`.

Версия записана в трёх местах: `CMakeLists.txt`, аргумент `make_installer.sh` в workflow, этот файл.
